# ⚡ Power Financeiro

Sistema de gestão financeira para Power Eletric / Power Equipamentos.

## Como rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Como publicar online (gratuito)

1. Crie conta em https://github.com
2. Crie um repositório novo chamado `power-financeiro`
3. Faça upload de todos os arquivos desta pasta
4. Crie conta em https://share.streamlit.io
5. Clique em "New app" → selecione o repositório → selecione `app.py`
6. Clique em Deploy — em 2 minutos está online!
